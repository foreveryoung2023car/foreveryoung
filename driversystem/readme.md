# 旅乘派車系統 ・ Google Sheets 欄位規格表 v2.0

> 對應前端原型：`dispatch-admin-v13.html`
> 試算表：[旅乘司機管理](https://docs.google.com/spreadsheets/d/1Z-5sCjox_wPRTgRqPNNfcxGjx6R78CRt8Lf0qgV_ABM/edit)
> v2 更新日：2026/05/22
> v2 變更：日期格式改 `YYYY/MM/DD`、預設費用新增範例、語言預設、狀態改中文、登入只要帳號

## 通則

1. **舊資料保留**　所有現有資料不動，新增欄位留空
2. **欄位順序**　新增欄位附在現有欄位後方
3. **多值欄位**　用半形逗號分隔，如「機場接送,一日遊,富士山」
4. **日期格式**　統一 `YYYY/MM/DD`（補零），例：`2026/05/22`
5. **時間格式**　統一 `HH:MM` 24h，補零
6. **金額**　純數字，單位日圓
7. **登入暫無密碼**　只用「帳號（電子郵件）」辨識，先讓大家看介面，未來再加密碼層
8. **派車狀態**　全部使用**中文**儲存與顯示

# 三、公式建議

## 司機表自動統計

P 欄（累積趟次）：
```
=COUNTIFS('派車紀錄'!E:E, A2, '派車紀錄'!AJ:AJ, "完成")
```

Q 欄（平均評分）：
```
=IFERROR(AVERAGEIFS('派車紀錄'!AH:AH, '派車紀錄'!E:E, A2, '派車紀錄'!AH:AH, ">0"), "")
```

R 欄（評價數）：
```
=COUNTIFS('派車紀錄'!E:E, A2, '派車紀錄'!AH:AH, ">0")
```

S 欄（本月應領 = 完成的費用 + 獎金 - 扣費）：
```
=SUMIFS('派車紀錄'!AG:AG, '派車紀錄'!E:E, A2,
        '派車紀錄'!C:C, ">="&TEXT(EOMONTH(TODAY(),-1)+1,"yyyy/mm/dd"),
        '派車紀錄'!AJ:AJ, "完成")
+ SUMIFS('訂單獎懲'!F:F, '訂單獎懲'!C:C, A2, '訂單獎懲'!E:E, "獎金",
        '訂單獎懲'!J:J, ">="&TEXT(EOMONTH(TODAY(),-1)+1,"yyyy/mm/dd"))
- SUMIFS('訂單獎懲'!F:F, '訂單獎懲'!C:C, A2, '訂單獎懲'!E:E, "扣費",
        '訂單獎懲'!J:J, ">="&TEXT(EOMONTH(TODAY(),-1)+1,"yyyy/mm/dd"))
```
